# アポ獲得の通知（平日 1日3回）

目的：**新しくアポが取れたら、担当ディレクターに Slack の DM ですぐ知らせ、商談までにやること（前日の確認連絡・商談結果の記入）を渡す。**
（大石さんの要望「アポ確認後のSlack通知」。11/4）

## 0. 準備
- リポジトリ `kitahara-cyber/portal` の一番上で作業する。作業用フォルダは `work/`（最後に消す）。
- 読むだけ：JD シート `11K2kL-50gSeDtk8PTRUGJUfDsfoWu6GZNjyaYOeBZLI` のタブ「JD営業支援_商談管理表一覧v2」（全社の商談アポ管理表をまとめたもの）。
  列：A パートナー名／D SIS／E アポ取得日／F 商談日／G 時間／H 会社名（アポ先）／K 役職／P ヒアリング内容／S 進捗ステータス／T 商談結果
- 設定シート（社外秘）`12KOCRonS_yRM-y-PrH12S50_tHzXDQC-zMwwXk1s-DU`：「顧客」タブ（SIS・会社名・担当・状態）、「担当」タブ（SlackユーザーID）、「実行ログ」タブ（書くのはここだけ）。

## 1. 新しいアポを見つける
1. `JD営業支援_商談管理表一覧v2!A1:T12000` を get_values（大きいのでファイルに保存される）。
2. アポ取得日（E列）が **今日または前営業日** の行だけを取る（日付の形は `YYYY/MM/DD`。未来の日付や `1900/` で始まる行は無視）。
3. 「顧客」タブで SIS が稼働中（契約中・請求停止・「稼働中として扱う」の例外）の会社だけにする。
4. 「実行ログ」で、結果が `アポ通知済み` の行のうち **SIS・アポ先・アポ取得日** が同じものがあれば、通知済みなので外す（実行ログの「定例の日時」欄にアポ取得日、「予定名」欄にアポ先を入れている）。

## 2. 担当ディレクターに DM する
担当（「顧客」タブの担当。空なら JD「パートナー一覧」のメインディレクター）の SlackユーザーID に、担当ごと1通にまとめて送る。IDが無ければ北原（U09T80ZAMT3）へ。
```
🎉 新しいアポ <n>件
■ <お客様の会社名>様 → <アポ先>（<役職があれば>）
　商談：<M/D(曜) HH:MM（未定なら「日程調整中」）>
　相手の関心：<ヒアリング内容を60字以内に要約>
　やること：商談の前日に、お客様（またはアポ先）へ日時の確認連絡／商談後は共有シートの商談アポ管理表に結果を記入してもらう
（2件目以降も同じ形で）
（自動で送っています。出どころ：商談アポ管理表のまとめ）
```
- アポ先の担当者の氏名・メールアドレス・電話番号は書かない（会社名と役職まで）。
- 商談日が今日・明日のものは先頭に「⏰ もうすぐ」を付ける。

## 3. 記録
- 「実行ログ」に1件1行：実行日時／SIS／お客様の会社名／アポ取得日（定例の日時の欄）／アポ先（予定名の欄）／担当／`アポ通知済み`／送信済み・未送信
- 新しいアポが0件なら何も送らず、ログも書かない。
- `work/` を消す。コミットはしない（リポジトリのファイルは変えない）。
