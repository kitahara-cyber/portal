# セルコン 見込みボード（Apps Script版）

CS タスクボード（`board-app` ブランチ）と同じ作り。**データはリポジトリに置かない**（このリポジトリは公開）。画面のプログラムだけをここに置き、案件や数字は開くたびに Apps Script がスプレッドシート【AIOマスター】から読む。

| ファイル | 中身 |
| --- | --- |
| `src/index.html` | 画面の元のソース。直すのはここ |
| `src/build.py` | `src/index.html` から `app.js` を作る |
| `app.js` | 生成物。Apps Script が raw GitHub から読む（10分キャッシュ） |
| `Code.gs` | Apps Script に貼るサーバーのコード（控え） |

## 最初の設定（北原さん）

1. **Apps Script のプロジェクトを作る**：【AIOマスター】のスプシとは別に、新しい Apps Script プロジェクトを作る（スプシに紐づけない。既存のフォーム用 GAS とぶつからないように）。
2. **コードを貼る**：`Code.gs` の中身を貼って保存。
3. **スクリプト プロパティ**（プロジェクトの設定 → スクリプト プロパティ。値はチャットやリポジトリに書かない）

   | 名前 | 値 |
   | --- | --- |
   | `SHEET_ID` | 【AIOマスター】のスプレッドシートID |
   | `MEMBERS` | `[{"name":"金﨑","email":"…@writeup.co.jp"},{"name":"小池","email":"…"},{"name":"相原","email":"…"},{"name":"アルバイト","email":"…"}]`（name はスプシに書かれている担当名） |
   | `ADMINS` | 管理ボードを見られる人のメール（カンマ区切り。例：小口さん） |
   | `SLACK_WEBHOOK_URL` | アドレスエラーの通知先（または `SLACK_BOT_TOKEN` と `SLACK_CHANNEL`） |
   | `ANTHROPIC_API_KEY` | AI の提案・メール下書き・書き方の学習（なければ `GEMINI_API_KEY`。どちらもなければ定型文で動く） |

4. **`setup` を一度実行**：権限を承認し、スプシの右端に「担当」（商談議事録）と「アポ獲得日」（セミナー申込フォーム）の列を足す。すでにあれば何もしない。
5. **デプロイ**：デプロイ → 新しいデプロイ → 種類「ウェブアプリ」
   - 次のユーザーとして実行：**ウェブアプリケーションにアクセスしているユーザー**
   - アクセスできるユーザー：**株式会社ライトアップ（writeup.co.jp）内の全員**
   - 出てきた URL を共有する。各メンバーは初回に Google の承認画面が出る（これが「Google連携」。本人の Gmail から送り、本人の権限でスプシを読む）。
   - 見られるのは writeup.co.jp の Google アカウントだけ。スプシの共有範囲もそのまま効く（スプシを見られない人はボードも開けない）。
6. **トリガー**（任意）：`proposeNew` を「時間主導・1時間ごと」に。議事録が入った直近3日の商談に、AI が次回アクションの提案を作る。

## 更新の手順

- 画面だけ直すとき：`src/index.html` を直す → リポジトリの一番上で `python3 sales-app/src/build.py` → `node --check sales-app/app.js` → `sales-app` ブランチに push → 最大10分で反映（すぐなら Apps Script で `refreshApp` を実行）。
- サーバーも直すとき：`Code.gs` を直して push（控え）→ Apps Script に貼り替え → デプロイを管理 → 既存のデプロイを編集して「新バージョン」（新しいデプロイを作ると URL が変わる）。
- `main`（お客様ポータル）と `board-app`（CS ボード）は触らない。

## 守ること

- このリポジトリは公開なので、スプシの中身・メールアドレス・キー類を **コードやコミットに入れない**。スプレッドシートIDもスクリプト プロパティに置く。
- お客様へのメールは、担当が画面で文面を確認して「送信する」を押したときだけ送る（自動送信しない）。
- Slack に送るのはアドレスエラーだけ。
- まだできていないこと：Gmail の返信の取り込み（受信の画面）、MCP 連携、もう一方のチーム・CS の数字を管理ボードに出すこと。
